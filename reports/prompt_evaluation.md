# Prompt Evaluation Report

## Objective
The objective was to compare prompt versions and evaluate whether clearer instructions and constraints improved the quality of AI responses.

## Evaluation Criteria
- Accuracy: Does the response satisfy the task?
- Relevance: Does it stay focused?
- Clarity: Is the output easy to understand?
- Consistency: Does it follow the requested format?

| Prompt | Version | Accuracy | Relevance | Clarity | Result |
|---|---|---:|---:|---:|---|
| Summarisation | V1 | 7/10 | 8/10 | 7/10 | Average |
| Summarisation | V2 | 9/10 | 9/10 | 9/10 | Good |
| Classification | V1 | 8/10 | 8/10 | 7/10 | Good |
| Classification | V2 | 9/10 | 9/10 | 9/10 | Excellent |
| Content Generation | V1 | 7/10 | 8/10 | 7/10 | Average |
| Content Generation | V2 | 9/10 | 9/10 | 9/10 | Good |

## Findings
Version 2 prompts generally performed better because they included clearer instructions, explicit output requirements and useful constraints.

## Conclusion
Prompt engineering is not only about asking a question. Defining the role, context, task, constraints and expected output format can make AI responses more consistent and useful.
